# Scope

## 1. 対象

本リポジトリは、売上を直接創出しないが、事業の成立、継続、統制、資源配分、学習を担う機能を対象とする。

### 機能領域

1. 経営ガバナンス・意思決定
2. 戦略・予算・ポートフォリオ
3. 財務・会計・税務・資金
4. 法務・契約・コンプライアンス
5. リスク・内部統制・内部監査
6. 人事・労務・組織
7. 調達・購買・ベンダー・資産
8. IT・データ・AI・情報セキュリティ
9. ナレッジ・文書・記録管理
10. 総務・施設・BCP・インシデント
11. 経営秘書・社内コミュニケーション

## 2. 成果物の範囲

- 参照アーキテクチャ
- オペレーティングモデル
- データモデルとJSON Schema
- AIエージェント定義
- 業務プロトコル
- 権限・リスク・統制モデル
- 例外処理とエスカレーション仕様
- Phase別導入仕様と手順書
- 領域別業務仕様
- テンプレート、実装例、テスト仕様
- 文書および実装の変更管理規約

## 3. 境界

売上部門の活動であっても、以下は対象に含む。

- 契約統制
- 請求・入金・会計処理
- 価格・予算・投資判断
- 顧客データの保護
- 品質保証
- 法令・規程遵守

顧客への価値提供そのもの、商品固有の製造・提供アルゴリズム、営業戦術の詳細は原則として対象外とし、共通基盤との接続仕様のみ扱う。

## 4. 前提

- 複数法人、複数部門、複数システムを扱えること
- AIモデルと実行ツールは交換可能であること
- 人間、AI、外部組織を同一の業務グラフ上で扱えること
- 法令、契約、社内規程を上位制約とすること
- 高影響な判断に人間の責任と承認を残すこと
