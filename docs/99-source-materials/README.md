# Source Materials

このディレクトリには、正式な文書体系を作る前に作成された構想資料、議論記録、初期要件を保存する。

## 位置付け

- 初期構想資料は設計意図と論点を保存する一次資料である。
- `draft`または`source`として扱い、直接の実装規範にはしない。
- 正式仕様へ採用する内容は、上位文書、共通モデル、Phase仕様、領域仕様へ分解して移行する。
- 正式仕様と矛盾する場合、正式仕様を優先する。

## 移行規則

初期資料から正式仕様へ内容を移す場合、次を明示する。

1. 移行先の文書パス
2. 採用した要件
3. 変更または棄却した要件
