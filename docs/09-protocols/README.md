## Required Elements

- 目的
- 開始条件
- 参加主体
- 入力と出力
- メッセージまたはイベント
- 状態遷移
- タイムアウト
- 再試行
- 代替処理
- エスカレーション
- 終了条件
- Evidence
- セキュリティと権限
- 正常・異常シナリオ

プロトコルは特定の業務領域やツールに依存させず、領域仕様または実装仕様から参照する。
